# Sorry Page

A tiny, playful apology microsite built with plain HTML, CSS, and JavaScript.

It turns a two-button joke into a small interaction study:

- the “Not accepted” action gently shrinks after each click
- the primary action resolves into a simple thank-you state
- everything runs in one file with zero dependencies
- the page stays usable with keyboard navigation and reduced-motion preferences

## Run locally

No build step is required.

```bash
python -m http.server 5500
```

Then open <http://localhost:5500>.

## Why it exists

Small projects are a good place to practice pacing, feedback, and restraint. This one is intentionally lightweight: one idea, one interaction loop, and a clear finish state.
